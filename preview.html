Add it in Gmail

  1. Click Copy signature above (or select the signature in the preview and copy).
  2. Open Gmail → Settings (gear) → See all settings → General.
  3. Scroll to Signature, create or edit one, then paste.
  4. Set it as the default for new emails and replies, then Save changes.
