# Personal Gmail signature

HTML email signature for **Sivaruban Thaksigan**, styled after a circular-portrait layout with teal accents.

Details come from [portfolio-thaksigan.vercel.app](https://portfolio-thaksigan.vercel.app/).

## Use it in Gmail

1. Open `preview.html` in a browser (or run `python -m http.server` in this folder).
2. Click **Copy signature**.
3. Gmail → Settings → **See all settings** → **General** → **Signature**.
4. Paste, set as default, **Save changes**.

Copy from the preview page (or paste `email.html`) so Gmail keeps the public photo and icon URLs. Images are hosted from this GitHub repo via jsDelivr, which Gmail can load.
